RUE'S 18TH BIRTHDAY GREETING

Files:
- index.html: the birthday page
- style.css: layout, colors, animations, responsive styling
- script.js: interactive birthday wish, sparkles, and confetti

How to open:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another browser.
3. Click "Make a birthday wish" to see the surprise.

You can edit the greeting text directly in index.html. The page uses Google Fonts when internet is available; the page still works without them.
